# Project Summary
This project develops a Bible presentation tool for live streaming via OBS Studio (Open Broadcaster Software). It provides a user-friendly interface for displaying Bible verses and related content, specifically tailored for church services and religious events. The tool supports Tamil Bible translations and includes features for verse selection, live display, customizable settings, and background image options, significantly enhancing the streaming experience for users.

# Project Module Description
- **Bible Search**: Enables users to search for Bible verses by book, chapter, and verse, now with a range feature to add multiple verses at once.
- **Verse Queue**: Manages the list of selected verses for live display.
- **Display Settings**: Customizes the appearance of displayed verses, including font size, colors, background settings, and background images.
- **Live Preview**: Provides a live view of how verses will appear during a stream.
- **Sync Manager**: Synchronizes display settings and verse data across multiple tabs or instances using `BroadcastChannel` and localStorage for cross-tab communication.
- **Data Loader**: Loads complete Bible verse data at runtime from JSON files, supporting over 31,000 verses.

# File Description Inventory
- **README.md**: Project overview and setup instructions.
- **package.json**: Project dependencies and scripts.
- **src/**: Contains all source code, including components, pages, and assets.
- **public/**: Static files such as images and icons.
- **prerender/**: Scripts for generating static routes and sitemaps.
- **assets/**: Contains image resources for the application.
- **data/tamil-bible.ts**: Contains interfaces and functions for managing Bible verse data loaded from JSON.

# Technology Stack
- **React**: Frontend library for building user interfaces.
- **TypeScript**: For type safety and enhanced developer experience.
- **Vite**: Build tool for faster development and production builds.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **React Router**: For handling routing in the application.

# Usage
1. Install dependencies:
   ```bash
   pnpm install
   ```
2. Build the project:
   ```bash
   pnpm run build
   ```
3. Run the application:
   ```bash
   pnpm run start
   ```
